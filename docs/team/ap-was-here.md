# Aishwarai Pratiksha's Project Portfolio

## Project: TutorConnect

TutorConnect is a JavaFX desktop application for freelance private tutors.
Its command interface manages student contacts, academic records, payments
and recurring lessons.

**Responsibilities:** Guardian contacts, subject verification and monthly payments.
