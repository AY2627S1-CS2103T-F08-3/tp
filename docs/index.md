# TutorConnect

[![CI Status](https://github.com/AY2627S1-CS2103T-F08-3/tp/actions/workflows/gradle.yml/badge.svg)](https://github.com/AY2627S1-CS2103T-F08-3/tp/actions/workflows/gradle.yml)
[![codecov](https://codecov.io/gh/AY2627S1-CS2103T-F08-3/tp/graph/badge.svg)](https://codecov.io/gh/AY2627S1-CS2103T-F08-3/tp)

![Ui](images/Ui.png)

**TutorConnect is a desktop application for freelance private tutors to organise student contacts, track lesson schedules, and manage parent communications.** It combines a fast Command Line Interface (CLI) with a Graphical User Interface (GUI).

* If you are interested in using TutorConnect, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing TutorConnect, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
